Tentang Bahasa Python

Python adalah bahasa pemrograman tingkat tinggi yang dirancang agar mudah dibaca dan dipelajari (filosofi **readability**).
Diciptakan oleh Guido van Rossum, Python sangat populer di berbagai bidang, mulai dari pengembangan web hingga ilmu data.
Sintaksnya yang bersih memungkinkan developer untuk menulis kode yang kompleks dalam waktu lebih singkat.

Python memiliki komunitas besar dan kaya akan pustaka (*libraries*) yang siap pakai.   Untuk mengunduh interpreter resminya, klik tautan berikut: Unduh Python Resmi

Informasi Singkat

Aspek Teknis
Bersifat interpreter dan dinamis
Mendukung paradigma OOP (Object-Oriented Programming)
Memiliki *Global Interpreter Lock* (GIL)

Keunggulan Python

  1. Sintaks yang sederhana dan jelas
  2. Serbaguna (Data Science, Web, Otomasi)
  3. Komunitas besar dan dokumentasi lengkap
